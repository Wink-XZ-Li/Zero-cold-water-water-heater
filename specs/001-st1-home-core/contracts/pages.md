# 页面合约：ST1 Pro 首页核心

**Phase**: 1 — Design  
**Date**: 2026-08-12

## 路由

| 路由 | 路径 | 名称 | Feature |
|------|------|------|---------|
| `/` | `/pages/home/index` | Home | 首页主控 |
| `/zero-cold-placeholder` | `/pages/zero-cold-placeholder/index` | ZeroColdPlaceholder | 设置定时占位 |

`routes.config.ts` MUST 注册以上路由。占位路由名在实现时可微调，但 MUST 保持稳定以便 002 替换页面实现时少改首页入口。

## 首页信息架构（逻辑区块）

以 Figma 首页节点为准，逻辑上至少包含：

1. **顶栏**：设备名/返回（SmartUI `NavBar` 或设计等价）
2. **主控**：开关、模式、设定温度
3. **状态**：出水温度、工作状态
4. **安全**：故障摘要（有故障时）
5. **条件状态**：火焰/水流（设计有则显示）
6. **零冷水入口**：摘要 + 进入占位页

## 占位页信息架构

1. **顶栏**：返回首页
2. **说明区**：明确「设置定时」等能力后续版本提供（不伪装已完成）
3. **无**：定时列表、时间选择器、保存按钮

## 导航规则

- 首页 → 占位页：正向进入
- 占位页 → 首页：返回（`navigateBack` 优先）；避免重复堆栈
- 禁止从占位页跳转到未实现的设置子页

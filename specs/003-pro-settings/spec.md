# Feature Specification: ST1 Pro 专业参数（瀑布浴等）

**Feature Branch**: `003-pro-settings`

**Created**: 2026-08-13

**Status**: Ready for planning

**Input**: 路线图 003「其余设置/专业参数」+ Ardot「方案修改」展开帧 `55:864` / `55:954`（瀑布浴、能耗报告入口）及物模型能力清单。

**Clarifications（2026-08-13）**:
- Q1=A：本包仅实现设计稿已展示的「瀑布浴 + 能耗报告入口」；变升/浴缸流量/回水温差/点动/保温时长等不纳入
- Q2=B：能耗报告入口进入预留的 004 页面壳（空图表区 + 说明），完整曲线与统计数据仍属 004

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 首页开启/关闭瀑布浴（增压）(Priority: P1)

用户在首页主控区下方看到「瀑布浴」行（副文案说明可增加用水水压），可通过开关开启或关闭瀑布浴能力；开关状态与设备一致。

**Why this priority**: 正式设计稿已给出信息架构与文案，是 003 可独立演示的最小价值切片。

**Independent Test**: 仅验证瀑布浴开关读写与离线/关机禁用策略，不依赖能耗报告页。

**Acceptance Scenarios**:

1. **Given** 首页已加载且设备在线、电源开启, **When** 用户查看列表区, **Then** 可见「瀑布浴」行及说明文案「开启后可增加用水时的水压」，开关反映当前增压状态
2. **Given** 瀑布浴当前关闭, **When** 用户打开开关, **Then** 设备收到开启指令，界面开关与设备上报一致
3. **Given** 瀑布浴当前开启, **When** 用户关闭开关, **Then** 设备收到关闭指令，界面与上报一致
4. **Given** 设备离线或电源关闭, **When** 用户尝试切换瀑布浴, **Then** 不允许生效或给出可理解提示，界面不呈现「已成功」的假状态

---

### User Story 2 - 首页能耗报告入口与 004 页面壳 (Priority: P2)

用户在瀑布浴下方看到「能耗报告」入口；点击后进入能耗报告页面壳（布局可对照 `55:1044`：用水/用气切换位、日周月年区、空图表区、误差说明文案），但**不**拉取或绘制真实用量曲线；页面明确提示完整统计将在后续版本提供或当前为空态。

**Why this priority**: 设计展开帧已包含入口；预留页面壳可避免 004 返工，图表价值仍在 004。

**Independent Test**: 点击入口进入页面壳并可返回首页即可，无需真实用量数据。

**Acceptance Scenarios**:

1. **Given** 用户在首页展开列表区, **When** 查看能耗报告行, **Then** 入口可见并带进入指示
2. **Given** 用户点击能耗报告, **When** 导航完成, **Then** 进入能耗报告页面壳（可见标题与空图表/说明结构，不伪装为已完成数据能力）
3. **Given** 用户在该页, **When** 返回, **Then** 回到首页且瀑布浴等状态保持正确

---

### Edge Cases

- 设备离线时切换瀑布浴：不得静默假装成功
- 电源关闭时瀑布浴开关是否可操作：与首页其他可控项一致（默认随电源禁用）
- 快速连续拨动瀑布浴开关：最终状态须与设备上报一致，无长期错位
- 能耗报告页面壳无数据时：展示空态/说明，不得空白崩溃或报未捕获错误

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 首页 MUST 展示「瀑布浴」开关行，文案与说明对齐设计帧 `55:864` / `55:954`
- **FR-002**: 瀑布浴开关 MUST 绑定产品增压能力（用户可理解的「增压/瀑布浴」），读写状态与设备一致
- **FR-003**: 设备离线或电源关闭时，瀑布浴操作 MUST 遵循与首页主控相同的禁用/提示策略
- **FR-004**: 首页 MUST 提供「能耗报告」入口行；点击后 MUST 进入预留的能耗报告页面壳（对照 `55:1044` 信息结构：标题、用水/用气切换位、周期区、图表占位、误差说明可只读展示）
- **FR-005**: 本 feature MUST NOT 实现真实用水/用气曲线数据绑定、历史查询与可交互统计（属 004）；页面壳内切换控件可只读或禁用并说明后续开放
- **FR-006**: 本 feature MUST NOT 改动 001/002 已交付的主控、零冷水开关与定时列表主路径（可并列新增行）
- **FR-007**: 本 feature MUST NOT 实现变升、浴缸流量、回水温差、点动、保温时长、累计用气/用水调节或展示入口（已确认不纳入本包；待后续 feature 或补设计）
- **FR-008**: 能耗报告页面壳 MUST 支持返回首页；空态文案 MUST 让用户理解「图表与统计尚未可用」

### Key Entities

- **瀑布浴（增压）**: 用户可开关的用水增压能力，首页一行展示
- **能耗报告入口**: 首页导航入口
- **能耗报告页面壳**: 预留的 004 页面骨架（空图表 + 说明），不含真实统计数据

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 用户可在首页 10 秒内找到并完成一次瀑布浴开/关，界面与设备状态一致
- **SC-002**: 离线或关机场景下尝试切换瀑布浴，100% 不会出现「界面已开但设备未开」的持久错位（失败有提示或保持原态）
- **SC-003**: 从首页进入能耗报告页面壳再返回，连续 3 次往返无卡死、无错误页
- **SC-004**: 对照 Ardot `55:864`/`55:954`，瀑布浴与能耗报告两行的信息结构（标题/说明/控件类型）一致；页面壳对照 `55:1044` 具备可识别的空图表结构，无自创多余主入口

## Assumptions

- 视觉继续复用 001 伊莱克斯主题变量；设计权威为 Ardot 文件 `714289030938546` 方案修改页
- 瀑布浴对应物模型中的增压（瀑布浴）能力；命名以设计「瀑布浴」为准
- 004 负责完整能耗报告图表与统计；003 提供入口 + 页面壳
- 001/002 已合入当前分支基线，003 从 `002-zero-cold-schedule` tip 继续开发

## Out of Scope

- **004**：用水/用气真实曲线、日/周/月/年数据查询与交互统计
- 变升、浴缸流量、回水温差、点动、保温时长等专业参数 UI
- 云定时增删改（已由 002 交付）
- 未在正式设计出现且未获批准例外的自创设置页信息架构
- 故障码扩展、火焰/水流首页展示（若 001 已明确不挂载则本包不强制）
